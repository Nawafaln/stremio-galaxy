# Galaxy Anime multi-genre filter (community modification, GPL-3.0)

The Genres picker sits beside the catalog selector on Galaxy Anime discovery pages. Choose several checkboxes, then Apply. All selected genres must match (AND). Clear all resets genre selection. Genre names follow the interface language (Arabic/English); canonical upstream values remain English. The filter is scoped to the local Galaxy Anime addon, not other installed catalogs. Set enabled=false in portable_config/extensions/galaxy-anime-ui/filters-config.js and restart to disable its picker.

Verified DOM on web.stremio.com: selectable-inputs-container-* > selectable-inputs-*; on stremio.zarg.me the two selectors are direct children of selectable-inputs-container-*. Only partial class selectors are used. The original single-value genre menu is hidden only on Galaxy Anime routes and restored on navigation. Accessible native checkboxes, Escape/outside-click dismissal, viewport-clamped panel, RTL and reduced-motion are supported. URLs retain search and discard skip when a filter is applied; browser back/forward retains URL selections.

Verified upstream manifest: https://anime-kitsu.strem.fun/manifest.json. Its airing/popular handlers forward comma-separated genre values; its trending and search handlers ignore genre. For airing/popular, Galaxy forwards the filter and pagination to that upstream. For all filtered catalogs it additionally verifies genre relationships through https://kitsu.io/api/edge/anime?filter[id]=...&include=genres&page[limit]=20 using Accept: application/vnd.api+json (application/json returns HTTP 406). This prevents accepting entries without all selected genre facts. Public metadata calls contain title IDs and genre preferences, no account credentials. Results/genre facts are cached in memory for five minutes.

Trending and search operate on the complete bounded set returned by their upstream handlers (trending currently 50 titles; search up to 20). Galaxy filters that set and then pages it in groups of 20; it does not claim to search all anime for the trending list. Missing genre facts are excluded from filtered results. Airing/popular paginate upstream normally. The catalog preview synopsis and Kitsu playback IDs are preserved as before. Machine translation remains removed.

Local /genres.json exposes the verified genre list with Arabic labels. The manifest declares genre for every Galaxy catalog including search; addon ID and manifest URL are unchanged. Existing Galaxy installations receive the picker through the updated extension; no account addon installation is performed by this feature.

Bundled Node 18 also passes the catalog/protocol tests. Real network AND checks returned One Piece for airing; 20 popular results; 9 trending results; and 3 Fullmetal search results. No mismatching genres passed.

Build: no native rebuild is required. Copy curated source modules to dist/win-x64/galaxy-anime and the extension to dist/win-x64/portable_config/extensions/galaxy-anime-ui, restart Galaxy, then run node build/package-installer.js. Installer packaging already includes these source directories and excludes used profile/private config files.

Native verification: in the actual D installation, the Genres button rendered beside Galaxy Anime — Airing. Selecting Action and Adventure kept both checkboxes checked; Apply produced ?genre=Action%2CAdventure, the button showed Genres (2), and the grid returned One Piece only. The popup is portaled to body to avoid transformed theme containers offsetting fixed positioning. Input appearance is explicitly restored against the remote UI reset CSS.

## Isekai extension (2026-10-22)
The picker now includes Isekai / إيسيكاي (عالم آخر), bringing the list to 62 choices. It is NOT a legacy Kitsu genre. The live Kitsu categories endpoint filter[slug]=isekai identifies category 246 with slug isekai. The live anime endpoint supports filter[categories]=isekai together with filter[genres], sorting, status and pagination. No AniList mapping or title-name guessing is necessary.

isekai.cjs handles popular/airing using that category filter, with the original sort/status and preserved kitsu IDs. It verifies the returned category relationships before accepting entries. Existing genres can be combined with Isekai using AND. Trending/search filter their bounded upstream sets using the included categories relationship. A missing category does not count as an Isekai match. Kitsu classification may be incomplete or disputed; the app follows source classification.

Tests: node tests/galaxy-anime-isekai.test.cjs (also verified using bundled Node 18). Live checks returned 20 popular, 20 airing, 8 trending and 13 Re:Zero search results with Isekai category evidence. Actual Galaxy displayed Genres (1): Isekai and results including No Game No Life, Re:Zero and Overlord. Selecting multiple genres and older genre filters remain supported. Updated files: genres.json, genre-filter.cjs, isekai.cjs, server.cjs, extension manifest.json, test and this document.
