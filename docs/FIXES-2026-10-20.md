# Galaxy fixes — 2026-10-20

Community modifications; GPL-3.0 and upstream attribution retained.

* Poster metadata now accepts the actual community `a[class*="meta-item-container-"]` card, as well as official `meta-item-link-` links. The poster child and IMDb id are still required. No Kitsu lookup or OMDb request without a key.
* The six existing navigation destinations are grouped on the physical right of search. Original React routing and narrow-window sidebar fallback remain.
* Startup embeds `images/galaxy-splash.png`, uses elapsed-time logo entrance, orbit arcs and stars at a 16ms timer, then a 280ms fade into the UI. It never waits on an animation thread.
* Ending detection includes the explicit chapter title `Credits`. The actual Aoashi chapters were Intro 69–158, Credits 1314–1404, then Episode 1404–1475.99. The previous classifier rejected Credits. The ending seek stops at 1404, preserving the final scene. No guessed song timing is added when chapters are absent.

## Build / tests

Use `build/environment-d.ps1` and the VS2022 x64 developer environment, then `cmake --build cmake-build-release-x64`. Copy the executable into `dist/win-x64` with Galaxy closed. Keep the packaged `portable_config/scripts/anime_skip.lua` in sync with the source script.

Run `node tests/poster-hover.test.cjs`, `node tests/top-navigation.test.cjs`, `node tests/song-markers.test.cjs`, `node tests/skip-locale.test.cjs`; run `tests/song-segments.test.lua` with Lua/Fengari. The Lua regression uses the actual inspected Credits chapter list.

Live checks: hover an IMDb poster; verify the card inside its image and its exit animation. Verify all six links to the right of search. Restart for the Galaxy splash. In the inspected episode verify yellow boundaries at 21:54/23:24, enter Credits, and click Skip Outro; it must seek to 23:24.

Limit: episodes without a named song chapter still cannot supply reliable markers or a skip destination.

## Verified in the Windows app

* Poster card appeared inside the Spider-Man poster with 2026, IMDb 8.0 and genres; all six navigation links were on the right of search.
* Aoashi showed yellow Intro and Credits ranges. Clicking Skip Outro changed playback time to 00:23:24; the after-credits chapter remained available.
* The native Galaxy startup logo, orbit arcs and stars were captured onscreen; the splash then disappeared and the home page loaded. No splash-creation error was logged on the final launch.
* Unpacked extension content scripts were confirmed active in this WebView2 app (skip button and marker module flags plus actual MPV property events). The missing ending was the rejected Credits title, not an extension loading failure.
* The separate existing next-episode auto-selection displayed a source-detection error in this episode. It was outside these four fixes and remains unchanged.
* Temporary diagnostic script and native diagnostic route were removed.

The splash compatibility manifest is merged with MSVC's default manifest. Windows 8+ layered child-window support is documented by Microsoft: https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features and https://learn.microsoft.com/en-us/windows/win32/compatibility/application-executable-manifest .
